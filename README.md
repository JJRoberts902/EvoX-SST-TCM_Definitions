# Evo X / Ralliart TC-SST TCM Calibration Table Purpose Guide

## What this guide covers

This guide explains the practical purpose of every parent calibration table in the Mitsubishi Lancer Evolution X / Ralliart TC-SST family map pack. The definitions were grounded in the TriCore TC1766 `SPS6_MI_GS41_V3.10.0` firmware lookup paths and the supplied XML map definitions.

**Coverage:** 510 parent tables: **105 3D maps, 366 2D tables, and 39 1D parameters**. The 510 entries are three variant-specific records (Variant Code 0, Variant Code 2, and Variant Code 3) representing **170 unique calibration functions**. Each variant copy is listed separately below so a buyer can identify the exact XML item available in the pack.

## Why this map pack is useful

The map pack is designed for calibration users who want a readable map definition rather than a collection of anonymous placeholders. Shift tables are named by the gear transition they control, clutch tables identify clutch 1 or clutch 2, torque-coordination tables identify the shift phase they affect, and diagnostic tables explain the protection boundary they enforce.

The XML also identifies the actual lookup axes—such as RPM, input-shaft speed, engine torque, accelerator pedal position, vehicle speed, road load, longitudinal acceleration, clutch slip speed, clutch temperature, shift row, position error, and normalized shift progress. This makes the pack useful for understanding how a value is consumed before making a calibration decision.

There is no blanket XY swap rule. The axis order shown for each table follows the firmware lookup orientation and the XML definition; use the named X/Y roles rather than swapping every map by default.

This is a calibration reference, not a generic “map list.” Each description explains what the value or surface is intended to influence, what the axes represent, and why changing it can affect shift behavior, clutch protection, adaptation, or diagnostics.

## How to use the variant records

The same function appears under three variant codes because the firmware selects different calibration records for different controller/vehicle configurations. Do not assume that changing one variant changes the others. Confirm which variant the ROM selects before editing. The XML notes identify three code-selected calibration records with fixed firmware record spacing.

Axis names are shown as physical quantities where the firmware proves the conversion: engine speed/RPM, input-shaft speed, engine torque, accelerator pedal position, vehicle speed, longitudinal acceleration, road load, shift row, clutch slip speed, clutch temperature, position error, and normalized controller progress. Native controller units are retained where a physical conversion was not proven.

## Practical calibration guidance

- **Shift schedule changes** move the point at which the TCM requests a gear change. They do not, by themselves, guarantee a faster or safer shift; torque coordination and clutch pressure must remain compatible.
- **Shift and torque-coordination maps** determine how the request is executed: shaft-speed targets, torque intervention, clutch handover, synchronizer damping, shift ramps, and shift-fork timing.
- **Clutch-pressure maps** are directly related to engagement force and heat generation. Excessive pressure can create harshness and mechanical load; insufficient pressure can create slip and clutch damage.
- **Adaptation maps** control learning behavior. They should be adjusted only with a clear understanding of the live learned values and the clutch/fork hardware condition.
- **Drivetrain-model maps** affect the TCM's internal estimates. Incorrect ratio, loss-torque, or pressure-to-torque values can cause poor shift timing, incorrect torque intervention, or plausibility faults.
- **Diagnostic-threshold maps** are protection boundaries, not normal performance maps. Raising them can hide a mechanical or sensor problem; lowering them can create nuisance faults.
- **Scalar controls** are global limits and mode selectors. They can influence every operating condition in the selected variant and therefore deserve extra review before editing.

## Validation notes

The pack is intended for users who understand TC-SST calibration and have suitable logging, temperature monitoring, clutch adaptation procedures, and a known-good stock backup. Make one related change at a time, verify clutch slip and shift time, and confirm that the selected variant record is the one used by the target ROM. The descriptions explain intended function; they are not promises of a universal safe value for every vehicle, clutch, fluid, or software revision.
